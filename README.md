# 🎮 Coding Pacman Game

Interactive Pacman-style browser game developed using JavaScript, HTML5, and CSS3.
The project demonstrates DOM manipulation, game logic implementation, keyboard controls, and responsive UI interactions.

## ⚙️ Installation & Setup

```bash
# Clone repository
git clone https://github.com/BelSerhij/Coding-Pacman.git

# Open project folder
cd Coding-Pacman
```

Run `index.html` in your browser or use Live Server in VS Code.
